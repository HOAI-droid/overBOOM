## OVERBOOM 0.9.0 – jetzt auf allen Plattformen

OVERBOOM gibt es jetzt als App für **Windows, Mac, Linux, Android, iOS und Xbox** – und weiterhin im Browser. Alle Versionen kommen aus demselben Code, Spielstand und Inhalte sind überall gleich.

### Downloads
| Datei | Plattform |
|---|---|
| `OVERBOOM-Windows-Setup.exe` / `OVERBOOM-Windows.msi` | Windows 10/11 |
| `OVERBOOM-Mac.dmg` | macOS (Apple Silicon und Intel) |
| `OVERBOOM-Linux.AppImage` / `.deb` / `.rpm` | Linux |
| `OVERBOOM-Android.apk` | Android (direkt installieren) |
| `OVERBOOM-Android-GooglePlay.aab` | Android-Bundle für Google Play (nur für Entwickler) |
| `OVERBOOM-iOS-unsigniert.ipa` | iPhone/iPad (selbst signieren) |
| `OVERBOOM-Xbox.zip` | Xbox Series X\|S im Developer Mode |
| `OVERBOOM-Browser.html` | jeder Browser, offline |

### Neu
- **Desktop-Apps** (Windows, Mac, Linux) mit Vollbild und Kartenbild-Export in den Download-Ordner.
- **Handy-Apps** (Android, iOS): Querformat, echtes Vollbild, Bildschirm bleibt an, Vibration, Teilen-Menü für Kartenbilder und Einladungslinks.
- **Xbox-App**: komplett mit dem Controller bedienbar – Menüs, Textfelder, Regler, Controller-Symbole statt Tastatur-Hinweisen, B = Zurück, Beenden im Titelmenü, TV-sichere Ränder.
- Die Schrift liegt jetzt in der App – das Spiel startet komplett offline.

### Hinweise
- Die Apps sind noch nicht signiert. Windows zeigt eine SmartScreen-Warnung („Weitere Informationen“ → „Trotzdem ausführen“), am Mac beim ersten Start Rechtsklick → „Öffnen“.
- iOS: Die `.ipa` muss mit einem eigenen Apple-Konto signiert werden (z. B. Xcode, AltStore, Sideloadly).
- Xbox: Installation über das Device Portal, Anleitung in `docs/xbox.md` (liegt auch im Zip).
